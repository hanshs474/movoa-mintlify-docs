---
title: SDKs and frameworks
description: Official Movoa SDKs and framework integrations.
---

Every client talks to [movoa.ai](https://movoa.ai/?utm_source=mintlify&utm_medium=docs) using an API key from [movoa.ai/settings/apikeys](https://movoa.ai/settings/apikeys).

- **Python**: [`pip install movoa`](https://pypi.org/project/movoa/)
- **TypeScript / JavaScript**: [`npm install movoa-ai`](https://www.npmjs.com/package/movoa-ai)
- **LangChain**: [`pip install langchain-movoa`](https://pypi.org/project/langchain-movoa/)
- **Haystack**: [`pip install movoa-haystack`](https://pypi.org/project/movoa-haystack/)
- **Vercel AI SDK**: [`npm install movoa-ai-provider`](https://www.npmjs.com/package/movoa-ai-provider)
- **ComfyUI**: [ComfyUI-movoa](https://github.com/hanshs474/ComfyUI-movoa)
- **Go / Rust / Ruby / Nim**: [movoa-go](https://pkg.go.dev/github.com/hanshs474/movoa-go) · [movoa (crates)](https://crates.io/crates/movoa) · [movoa (gem)](https://rubygems.org/gems/movoa) · [movoa-nim](https://github.com/hanshs474/movoa-nim)
